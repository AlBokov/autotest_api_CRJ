## Цель проекта 🎯
Создание программы для автоматического тестирования протокола CRJ на основе документа `operation.yaml`. Проект упрощает проверку корректности работы API, автоматизируя отправку запросов и валидацию ответов.

## Стэк технологий 🛠️
- **Язык разработки:** Python 3.8+
- **Основные библиотеки:**
  - `PyYAML` — парсинг YAML-документации
  - `requests` — отправка HTTP-запросов
  - `jsonschema` / валидация ответов
  - `typing` — типизация кода
  - `logging` — логирование процессов

## Запуск 
1. Составить сценарий тестирования в файле list_of_operations.txt. Каждая операция начинается с новой строки, название операции можно посмотреть в документации или в README
2. Прописать нужные настройки в settings.txt
3. Добавить в папку config файл с документации operation.yaml
4. Запустить автотесты.
5. Отчетность по тестам можно посмотреть в логах. Папка логов создаться автоматически в корне проекта.


## Структура проекта
1. config/
    - list_of_opearation.txt - текстовый документ, содержит в себе сценарий автотетов. 
    - operation.yaml - swagger документ, содержит в себе полное описание api протокола CRJ. Именно отсюда берутся request и response для проверки. 
    - settings.txt - текстовый документ для хранения переменных.
2. src/
    - client.py - в скрипте создается клиент для правки request на терминал.
    - logger_config.py - в скрипте создается и настраивается логирование.
    - open_parser_yaml.py - в скрипте считывается operation.yaml файл. Формируется запросы и пример response для валидации.
    - settings.py - в скрипте считывается settings.txt файл и на его основе создаются переменные.
    - validator_response.py - в скрипте прописана логика проверки response.
3. autotest.py - в скрипте выполняются автотестирование.
4. main.py - в скрипте выполняется ручная отправка requests. Так же используется для отлатки.
5. README.md - описание проекта
6. requirements.txt - файл содержит необходимы библиотеки 

## Этапы разработки

9. Добавить GUI интерфейс.
